**Geological engineering student at UNI · applied geophysics · GIS · scientific software**

I build open and reproducible tools that connect geological interpretation,

I study Geological Engineering at Universidad Nacional de Ingeniería in Lima,
Peru. My work connects mineral exploration, environmental hydrogeology and
geological hazards with reproducible computational methods. Alongside software

## Working principles

- Preserve the original data and distinguish source evidence from derived products.
- Make CRS, datum, units, scale and NoData assumptions explicit.
- Separate successful software execution from scientific or geological validation.
- Prefer open formats and reproducible manifests for GIS deliverables.
- Ship tests, documentation and limitations alongside algorithms.
- Attribute datasets, scientific methods and third-party software clearly.
